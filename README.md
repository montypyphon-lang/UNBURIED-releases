# UNBURIED

Zombie battle royale. **Download the latest version from [Releases](https://github.com/montypyphon-lang/UNBURIED-releases/releases/latest).**

- New players: download **UNBURIED-Setup.exe** and run it (Windows may say "unrecognised app": click *More info* then *Run anyway*).
- Already installed? The game updates itself: when a new version is out, the lobby shows **UPDATE NOW**.
